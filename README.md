## 📌 Overview

**GitFind** is a responsive **React Single-Page Application (SPA)** that integrates with the official **GitHub REST API (`api.github.com/users/{username}`)** to dynamically fetch and display developer profiles, avatars, bios, and public repository lists.

---

## ✨ Features

* **Live GitHub API Integration**: Asynchronous `fetch()` calls retrieving user metadata (`/users/{user}`) and repository collections (`/users/{user}/repos`).
* **Component-Based Architecture**: Modular React components (`Header`, `ItemList`, profile cards) managed with React Hooks (`useState`).
* **Dark Theme UI**: Clean developer-focused dark mode interface.

---

## 🚀 Running Locally

```bash
npm install
npm start
```
Open `http://localhost:3000` in your browser.
